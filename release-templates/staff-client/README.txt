NEXUZY LEDGER STAFF CLIENT

Download and install the desktop client for this computer:

Windows:
  Nexuzy-Ledger-Staff-Windows-Setup.exe
  Run the installer and use the Nexuzy Ledger Staff desktop icon.

macOS:
  Nexuzy-Ledger-Staff-macOS.dmg
  Open the DMG and drag the application into Applications.

Linux:
  Nexuzy-Ledger-Staff-Linux.deb
  or Nexuzy-Ledger-Staff-Linux.AppImage
  Install the DEB with your software installer, or make the AppImage executable
  and launch it.

First run:
  1. Choose the Nexuzy Ledger host on the local network, or enter its hostname/IP.
  2. Host setup is saved on this computer.
  3. Later, open the desktop icon and enter only your staff username and password.

Use "Change host" if the staff client shows a connection-error screen and the
business host needs to be selected again.

The staff client does not create a business server and does not create another
administrator account. The host administrator creates each staff account in:
Settings -> Users & devices.

Before the first secure connection, install the Nexuzy Lab Local Network CA
downloaded from Settings -> Users & devices -> Download device-trust certificate.
